使用说明

基本操作

  • 将文件拖入悬浮窗 → 常驻显示，随时取用
  • 单击文件 → 打开文件
  • 右键文件 → 打开 / 在文件夹中显示 / 移除 / 删除
  • 将文件拖出窗口 → 从列表中移出

边缘吸附与隐藏

  • 将窗口拖到屏幕边缘 → 自动吸附并隐藏为小圆点（触点）
  • 鼠标移到触点上 → 自动展开窗口（悬停模式）
  • 点击触点 → 展开窗口（点击模式）
  • 拖拽文件靠近触点 → 自动展开（可直接拖入）
  • 固定窗口（图钉按钮）→ 暂停自动隐藏

编辑模式与多选

  • 点击编辑按钮 → 进入编辑模式
  • 按住空白处拖动 → 框选多个文件
  • 随手单击空白 → 不会误触框选
  • 双击空白处 → 快速退出编辑模式
  • 全选 / 移出 / 删除 批量操作

文件夹浏览

  • 双击文件夹 → 进入查看内容
  • 顶部面包屑 → 点击任意层级快速返回
  • 安全模式：拖入的文件仅临时显示，不修改真实文件
  • 修改模式：拖入/拖出/删除会真实修改文件夹（请谨慎）

文件仓管理

  • 托盘菜单 → 新建文件仓 / 文件仓管理
  • 临时仓：仅存文件引用，拖出后引用从仓中消失，不影响真实文件
  • 引用仓：绑定真实文件夹，仓内内容为文件夹的实时引用
  • 底部状态栏 ← / → 键 → 在各文件仓间切换；点击序号圆点跳转
  • 左下角 + 按钮 → 快速打开文件仓管理

隐藏技巧

  • 顶部按钮长按拖动 → 自定义按钮顺序
  • 窗口太窄时 → 按钮自动收到"更多"菜单
  • 设置里滑块数值 → 双击可直接输入数字
  • 主题默认强调色 → 强调色设置里点"主题默认"恢复
